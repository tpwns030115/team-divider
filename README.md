# ⚽ 팀 나누기 (team-divider)

참가자 이름과 포지션을 입력하면, 고른 포메이션에 맞춰 포지션별로 균형 있게 팀을 랜덤으로 나눠 주는 웹 앱입니다.

설치나 서버 없이 HTML 파일 하나(`index.html`)만 브라우저로 열면 바로 사용할 수 있습니다.

## 주요 기능

### 참가자 입력
- 이름을 입력하고 포지션(골키퍼 / 수비 / 미드필더 / 공격)을 골라 추가합니다.
- **추가** 버튼 대신 **엔터**로도 추가할 수 있습니다. 한글 입력 중에 엔터를 눌러도 두 번 추가되지 않습니다.
- 참가자는 포지션별로 한 줄씩 나뉘어 보이고, 포지션마다 인원 수가 함께 표시됩니다.
- 이름 옆의 **×** 버튼으로 한 명씩 삭제하거나, **전체 삭제** 버튼으로 한 번에 지울 수 있습니다. 전체 삭제는 확인 창이 뜹니다.

### 포지션별 팀 나누기
- 팀 수는 **2~4팀** 중에서 고릅니다.
- 포메이션은 아래 다섯 가지 중에서 고릅니다. 팀마다 골키퍼 1명이 기본으로 들어갑니다.

  | 포메이션 | 골키퍼 | 수비 | 미드필더 | 공격 | 팀당 인원 |
  |---|---|---|---|---|---|
  | 4-3-3 | 1 | 4 | 3 | 3 | 11 |
  | 4-4-2 | 1 | 4 | 4 | 2 | 11 |
  | 3-5-2 | 1 | 3 | 5 | 2 | 11 |
  | 4-5-1 | 1 | 4 | 5 | 1 | 11 |
  | 3-4-3 | 1 | 3 | 4 | 3 | 11 |

- 설정 아래에 포지션별 **현재 인원 / 필요 인원**이 표시되고, 모자란 포지션은 빨간색으로 보입니다.
- 인원이 모자라면 팀을 나누지 않고, 어느 포지션에 몇 명이 더 필요한지 알려 줍니다.
- 포지션마다 참가자를 무작위로 섞은 뒤 팀마다 필요한 만큼 나눠 줍니다.
- 필요 인원보다 많이 남는 참가자는 **후보**로 팀마다 골고루 들어갑니다.

### 저장
- 참가자 목록, 팀 수, 포메이션이 브라우저(localStorage)에 자동으로 저장됩니다. 새로고침하거나 창을 닫았다 열어도 그대로 남아 있습니다.
- 팀 나누기 **결과는 저장되지 않습니다.**
- 시크릿 모드처럼 저장이 막힌 환경에서도 앱은 정상 동작하며, 저장만 되지 않습니다.

### 수정
- 참가자 이름을 누르면 이름과 포지션을 바로 고칠 수 있습니다.
- **엔터** 또는 **저장** 버튼으로 저장하고, **ESC** 또는 **취소** 버튼으로 취소합니다.
- 이름을 비워 두면 저장되지 않습니다.

### 결과 복사
- 팀을 나눈 뒤 **결과 복사** 버튼을 누르면, 카카오톡 같은 메신저에 붙여 넣기 좋은 텍스트로 복사됩니다.
- 브라우저의 클립보드 기능이 막혀 있으면 예비 방법으로 복사를 시도합니다.

복사되는 텍스트 예시:

```
⚽ 팀 나누기 (4-3-3)

[A팀]
골키퍼: 김민수
수비: 이준호, 박지훈, 최현우, 정성민
미드필더: 강동원, 윤재석, 한지민
공격: 오세훈, 서태웅, 임도윤
후보: 조영훈

[B팀]
골키퍼: ...
```

## 사용법

1. `index.html` 파일을 브라우저로 엽니다(더블클릭).
2. **참가자** 칸에 이름을 입력하고 포지션을 고른 뒤 **추가**를 누르거나 엔터를 누릅니다.
3. **설정**에서 팀 수와 포메이션을 고릅니다. 포지션별 인원 표시가 모두 초록색인지 확인합니다.
   - 예: 2팀, 4-3-3이면 골키퍼 2명, 수비 8명, 미드필더 6명, 공격 6명이 필요합니다.
4. **팀 나누기**를 누르면 아래 **결과**에 팀이 나옵니다. 다시 누르면 새로 섞어서 나눕니다.
5. **결과 복사**를 눌러 단톡방 등에 붙여 넣어 공유합니다.

> 참가자를 추가·수정·삭제하거나 팀 수·포메이션을 바꾸면 이전 결과는 지워집니다. 이때는 **팀 나누기**를 다시 눌러 주세요.

## 기술 스택

- HTML, CSS, 순수 JavaScript (외부 라이브러리 없음)
- 저장: 브라우저 localStorage
